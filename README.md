# Aayushi Birthday Surprise — GitHub Pages

This folder is a complete static website. Upload the **contents of this folder** to GitHub; no build command is needed.

## Fastest publishing method

1. Sign in at https://github.com.
2. Create a **public** repository named `aayushi-birthday`.
3. Open the repository, choose **Add file → Upload files**, and upload `index.html`, `styles.css`, `script.js`, `og.png`, and the entire `photos` folder.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main**, folder **/(root)**, then click **Save**.
7. After a few minutes, the site will be available at:
   `https://YOUR-GITHUB-USERNAME.github.io/aayushi-birthday/`

## Cleanest GitHub URL

For the shorter address `https://YOUR-GITHUB-USERNAME.github.io/`, create the repository with the exact name `YOUR-GITHUB-USERNAME.github.io` instead. A GitHub account can normally have only one such main Pages site.

## Important

- Keep the file and folder names unchanged.
- Upload the contents, not the ZIP file itself.
- GitHub Pages URLs still contain your GitHub username. To remove that too, connect a custom domain in **Settings → Pages → Custom domain**.
